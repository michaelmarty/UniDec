# UniDec documentation

UniDec provides Python and native tools for deconvolving mass and ion-mobility mass spectra. This site documents the Python interfaces, agent integration, and the complete module reference.

## Choose a starting point

- **Install or run UniDec:** See the [project README](https://github.com/michaelmarty/UniDec#readme) for installation, supported file types, GUI launch commands, and release information.
- **Automate UniDec with an agent:** Follow the [UniDec MCP agent interface](guides/agent-interface.md).
- **Use the Python package:** Browse the complete API reference below. A curated supported-API guide will be added in the next documentation phase.
- **Understand the architecture:** Start with the architecture section in the [project README](https://github.com/michaelmarty/UniDec#unidec-architecture) until the architecture guide is separated into this site.
